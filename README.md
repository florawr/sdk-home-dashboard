# OpenWrap SDK — Home & Dashboard (prototype)

High-fidelity, no-build prototype of the PubMatic OpenWrap SDK **Home** and
**Dashboard**, built in the Helios design system. Pure static HTML/CSS/JS.

## Pages
- `index.html` — Home (command center: Needs Your Attention, Performance Snapshot, notifications, Version Health drawer)
- `dashboard.html` — Dashboard (performance overview, Top Apps, By Ad Format, Version Health, Top Demand Sources)
- `notif-preview.html` — standalone notifications popover preview
- `home-wireframe.html` — early low-fi wireframe

## Run locally
No build step, no Node. From this folder:
```bash
python3 serve.py   # → http://127.0.0.1:5173/
```
Or just open `index.html` in a browser.
